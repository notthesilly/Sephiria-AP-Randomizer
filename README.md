# Sephiria Archipelago Randomizer

An [Archipelago](https://archipelago.gg/) integration for **Sephiria**.

This project is currently in early development. The current build focuses on allowing Sephiria runs to function as Archipelago goals, including chapter selection, multiple required clears, and optional unique-weapon requirements.

> **This is not yet a complete item/location randomizer.**

## Current Status

Current version: **v0.1.0-alpha**

The following functionality is currently implemented:

- Archipelago save creation
- Archipelago server connection and reconnection
- Selectable goal chapters from Chapters 1–6
- Multiple required chapter clears
- Optional unique-weapon requirement for counted clears
- Persistent clear progress through Archipelago
- Persistent tracking of previously used weapons
- Archipelago goal completion reporting

Item randomization, location checks, progression items, and broader randomizer logic are still under development.

## Requirements

- Sephiria on Steam
- MelonLoader
- Archipelago 0.6.7
